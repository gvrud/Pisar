# Писарь

Офлайн-приложение для Android: расшифровка аудиофайлов и голосовых заметок, краткое содержание,
поиск по расшифровкам, прослушивание, экспорт в TXT/DOCX. Без интернета и без сервисов Google Play.

- Android 8–16, minSdk 26, targetSdk 35
- Работает на устройствах с 2 ГБ ОЗУ (Vosk small, потоковая обработка)
- В приложении нет разрешения `INTERNET`

## Сборка

```
./gradlew :app:assembleRelease
```

Нужны JDK 17 и Android SDK 35. APK: `app/build/outputs/apk/release/app-release.apk`.

## Модель

Модель в APK не входит. Скачайте `vosk-model-small-ru-0.22.zip`
(https://alphacephei.com/vosk/models), перекиньте на телефон и импортируйте в приложении:
меню → «Модель распознавания». Можно хранить несколько моделей и переключаться между ними.
